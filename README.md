# JM-bot 漫画工具

在 MaiBot 的 QQ 群或好友私聊中查询作品、管理收藏、预览和下载。下载后端可生成 PDF 和 ZIP，队列与会话下载权限可在本机网页管理。

## 安装

首版支持 Windows，验证环境为 MaiBot 1.4.8、插件 SDK 2.23.0 和 SnowLuma 的 NapCat 适配器。NapCat 需要能读取 MaiBot 所在机器生成的文件。

1. 在 MaiBot 安装并启用 SnowLuma 的 NapCat 适配器。
2. 从插件市场安装 JM-bot。手动安装时，将 Release 源码解压到 MaiBot 的 `plugins/` 下，再在运行 MaiBot 的 Python 环境执行 `pip install -r 插件目录/requirements.txt`。
3. 打开插件配置，填入管理员 QQ。按需添加首次授权的群号。保存后重载插件。
4. 在授权会话发送 `/jm 帮助`。管理员也可以在授权的好友私聊测试。
5. 本机打开 `http://127.0.0.1:18081/`。初始管理员密码位于插件数据目录的 `admin-first-login.txt`。后台可调整会话权限和队列。端口冲突时可在插件配置修改端口。

可选的任务状态上报需要兼容的 `local.task-awareness` 插件，默认关闭。下载状态也可直接通过指令或管理后台查看。

## 指令

| 操作 | 指令 |
| --- | --- |
| 按关键词查 JM 码 | `/jm 搜索 关键词 [页码]` |
| 查作者作品 | `/jm 作者 作者名 [页码]` |
| 查看作者作品文字列表 | `/jm 作者 文本 作者名 [页码]` |
| 查看排行 | `/jm 排行 [文本] [关键词或类别] [榜单] [页码]` |
| 查看排行类别 | `/jm 排行 类别` |
| 查看详情或封面 | `/jm 详情 编号`、`/jm 封面 编号` |
| 生成预览 PDF | `/jm 预览 编号` |
| 下载整本 | `/jm 编号`、`/jm 编号 pdf`、`/jm 编号 zip` |
| 下载指定章节 | `/jm 编号 章节 1,3-5`、`/jm 编号 章节 1,3-5 zip` |
| 管理收藏 | `/jm 收藏 编号`、`/jm 取消收藏 编号`、`/jm 我的收藏` |
| 查看队列和自己的任务 | `/jm 队列`、`/jm 我的` |
| 查看下载进度 | `/jm 进度 [编号]` |
| 撤回自己发起的下载 | `/jm 撤回 编号` |
| 查看历史或失败记录 | `/jm 历史 [条数]`、`/jm 历史 失败 [条数]` |
| 查看专题帮助 | `/jm 帮助 查找`、`/jm 帮助 排行`、`/jm 帮助 下载`、`/jm 帮助 收藏`、`/jm 帮助 任务` |

方括号里的内容可以省略，编号填纯数字。榜单支持日榜、周榜、月榜和总榜。英文别名包括 search、info、cover、preview、my、history 和 help。
