# JM-bot 漫画工具

JM-bot 的 MaiBot 适配插件。在授权的 QQ 群或好友私聊发送 `/jm` 命令，即可搜索漫画、查看封面和详情、管理收藏，或将预览与下载文件发回当前会话。

[下载发行版](https://github.com/x1a0he1/maibot-jm-bot/releases/latest) · [反馈问题](https://github.com/x1a0he1/maibot-jm-bot/issues) · [许可证](LICENSE)

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 搜索与排行 | 按关键词或作者查作品，浏览指定类别和时间范围的榜单。结果可以翻页。 |
| 详情与预览 | 用作品编号查看资料、取封面，或生成前几页的 PDF 预览。 |
| PDF 和 ZIP 下载 | 下载整本或指定章节。任务进入队列，处理完成后由 QQ 发送文件。 |
| 收藏与任务 | 收藏按 QQ 账号保存。可查询队列、查看自己在当前会话中的任务和历史，或撤回自己的任务。 |
| 本机管理后台 | 管理群聊和私聊权限、全局开关、任务队列、帮助文本及后台管理员。 |

## 安装

### 环境要求

| 项目 | `v1.0.0` 要求 |
| --- | --- |
| 系统 | **Windows**。MaiBot 的运行进程也应在 Windows 上。 |
| MaiBot | 清单声明支持 `1.4.8–1.4.99`，验证环境为 `1.4.8`。 |
| 插件 SDK | 清单声明支持 `2.23.0–2.23.99`，验证环境为 `2.23.0`。 |
| QQ 适配器 | 启用 **SnowLuma 的 NapCat 适配器**并确认 QQ 在线。NapCat 需要能读取插件生成的本机文件，才能上传 PDF、ZIP 和封面。 |

### 从插件市场安装

1. 在目标 MaiBot 实例的 WebUI 打开「插件市场」，搜索 **JM-bot 漫画工具**。
2. 安装兼容的版本并启用插件。麦麦会按 [_manifest.json](_manifest.json) 处理声明的 Python 包依赖。
3. 打开插件设置，填写管理员 QQ。需要在群里用时，再添加要授权的群号。
4. 保存并重载插件。向机器人发送 `/jm 帮助` 确认启动成功。

下载后端已经随插件打包。SnowLuma／NapCat 负责 QQ 收发，需要在 MaiBot 中单独启用与连接。

### 手动安装

市场搜索不到时，可通过 [GitHub Release](https://github.com/x1a0he1/maibot-jm-bot/releases/latest) 下载 **Source code (zip)**。

1. 将解压目录放在目标实例的 `plugins/` 下，例如 `plugins/maibot-jm-bot/`。该目录下应直接看到 `plugin.py` 和 `_manifest.json`。
2. 用**启动 MaiBot 的同一个 Python 环境**安装依赖。以下示例从 MaiBot 实例根目录执行。

```powershell
python -m pip install -r "./plugins/maibot-jm-bot/requirements.txt"
```

3. 通过 WebUI 加载并启用插件，填写管理员 QQ，保存后重载。

## 首次配置

在插件设置里修改即可。下表中的名称对应本地 `config.toml` 的 `[plugin]` 配置项。

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `operator_qq` | 空 | **必填**。填写负责管理插件的用户 QQ 号，只填数字。该账号用于登录后台，其好友私聊会在首次初始化时获得下载权限。 |
| `initial_group_ids` | `[]` | 首次为哪些 QQ 群创建下载授权。留空时不自动授权任何群。 |
| `download_port` | `17860` | 本机下载服务端口。与其他实例冲突时改用空闲端口。 |
| `admin_port` | `18081` | 本机管理后台端口，与下载服务端口必须不同。 |
| `task_awareness_enabled` | `false` | 选填。已安装兼容的 `local.task-awareness` 插件时，可开启后台任务上报。 |
| `source_url` | 空 | 正常使用发行版时留空。自行修改部署时，填写当前运行版本对应源码的 HTTPS 地址。 |

`initial_group_ids` 只给之前没有权限记录的群做初始化。后续授权或撤销请到管理后台操作，从列表移除一个旧群号不会撤销已有权限。保存配置后重载插件，端口和管理员设置才会应用。

### 快速验收

1. 用管理员 QQ 在机器人好友私聊发送 `/jm 帮助`，应看到指令菜单和源码链接。
2. 用 `/jm 搜索 关键词` 找到一个可访问的作品，复制返回的**数字编号**。
3. 发送 `/jm 详情 编号` 确认作品，再用 `/jm 预览 编号` 检查 QQ 能否收到 PDF。
4. 在初始授权群再发送一次 `/jm 帮助`，确认群聊权限生效。

## 指令速查

表中的 `编号`、`关键词` 和 `作者名` 都要换成实际文字。方括号中的参数可以省略，翻页从第 1 页开始。

| 操作 | 指令 |
| --- | --- |
| 打开指令目录 | `/jm` 或 `/jm 帮助` |
| 查看专题帮助 | `/jm 帮助 查找`、`/jm 帮助 排行`、`/jm 帮助 下载`、`/jm 帮助 收藏`、`/jm 帮助 任务` |
| 按关键词搜索 | `/jm 搜索 关键词 [页码]` |
| 查作者作品 | `/jm 作者 作者名 [页码]` |
| 查作者作品，只发文字 | `/jm 作者 文本 作者名 [页码]` |
| 看排行 | `/jm 排行 [文本] [关键词或类别] [榜单] [页码]` |
| 列出排行类别 | `/jm 排行 类别` |
| 查看详情或封面 | `/jm 详情 编号`、`/jm 封面 编号` |
| 获取 PDF 预览 | `/jm 预览 编号` |
| 下载整本 | `/jm 编号` 默认 PDF，也可显式写 `/jm 编号 pdf` 或 `/jm 编号 zip` |
| 下载指定章节 | `/jm 编号 章节 1,3-5` 或 `/jm 编号 章节 1,3-5 zip` |
| 添加或取消收藏 | `/jm 收藏 编号`、`/jm 取消收藏 编号` |
| 查看我的收藏 | `/jm 我的收藏` 或 `/jm 收藏` |
| 查队列或自己的任务 | `/jm 队列`、`/jm 我的` |
| 查最近或指定作品进度 | `/jm 进度 [编号]` |
| 撤回自己在当前会话提交的任务 | `/jm 撤回 编号` |
| 查最近记录或失败记录 | `/jm 历史 [条数]`、`/jm 历史 失败 [条数]` |

可用英文别名包括 `search`、`info`、`cover`、`preview`、`my`、`history` 和 `help`。详情也可以用 `/jm 看 编号`。

### 常用组合

- `/jm 排行 文本 短篇 周榜 2` 查看短篇周榜第 2 页，只回文字。榜单可选日榜、周榜、月榜和总榜。
- `/jm 12345 章节 1,3-5 zip` 将示例作品的第 1、3、4、5 章打成 ZIP。编号和章节都要换成实际值，用英文逗号分隔不同章节。
- 下载提交后先用 `/jm 进度` 查看状态。失败时可用 `/jm 历史 失败 5` 查看近期失败记录。

## 管理后台

后台默认监听本机 `127.0.0.1:18081`，请在运行 MaiBot 的 Windows 机器上打开。修改了 `admin_port` 时，在地址里换成自己的端口。

首次启动后，在插件数据目录的 `admin-first-login.txt` 读取初始密码，用配置的管理员 QQ 登录。后台密码和 QQ 登录密码是两套凭据。超级管理员可以在「管理员账号」页重置密码或管理其他后台账号。

| 页面 | 用途 |
| --- | --- |
| 状态 | 查看服务心跳和全局下载开关。 |
| 会话权限 | 按群号或好友 QQ 添加会话，再为它打开「下载」。新添加的会话默认关闭下载，可单独启用下载黑名单。 |
| 队列 | 查看任务阶段，取消任务、调整待处理任务的优先级或管理队列记录。 |
| 帮助文本 | 修改 QQ 中的 `/jm 帮助` 内容，也可以恢复之前保存的版本。 |
| 管理员账号 | 超级管理员可新增管理员、重置密码或删除其他管理员账号。 |

基础收发经由 MaiBot 的 SnowLuma 适配器。后台的 NapCat 扫码、登录状态和通讯录等监控功能还有额外的 NapCat 管理接口依赖，用 MaiBot 下载和发文件时可以只使用「会话权限」与「队列」。

## 数据和日志

持久数据位于当前 MaiBot 实例的 `data/plugins/github.x1a0he1.maibot-jm-bot/`。不同实例各有自己的数据目录。

| 文件 | 内容 |
| --- | --- |
| `user.sqlite3` | 用户收藏 |
| `queue.sqlite3` | 下载队列和任务历史 |
| `conversation.sqlite3` | 群聊、私聊权限及全局开关 |
| `admin.sqlite3` | 管理后台账号与配置记录 |
| `download.log`、`admin.log` | 下载进程、管理后台日志 |

迁移或备份时，可以先停用插件，再备份对应的数据目录和插件配置。反馈问题时请附相关日志片段，先去掉初始密码、访问令牌和无关的 QQ／群号。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 插件已启用，`/jm` 提示填写管理员 QQ | 设置里填 `operator_qq`，保存后重载。 |
| 提示「JM 下载服务还没连接」 | 检查 SnowLuma／NapCat 是否在线，查看 `download.log` 及插件加载日志，确认 `download_port` 没有被其他进程占用。 |
| 私聊能用，群里提示尚未启用 | 在后台「会话权限」找到目标群，打开「下载」，并检查该群的下载黑名单和全局下载开关。 |
| 能查详情，但文件发不出来 | 先在「队列」或 `/jm 历史 失败` 查看状态。核对 NapCat 能否读取这台机器上的输出文件，以及机器人在群内能否上传文件。 |
| 提示「群文件尚未确认」 | 先检查群文件列表。上传请求已提交，可能只是确认延迟，先核实再重试。 |
| 后台网页打不开 | 在运行 MaiBot 的机器上访问，核对 `admin_port` 和 `admin.log`。同一台 Windows 上运行多套实例时，各实例的下载和后台端口都需要错开。 |
| 手动安装后提示缺少模块 | 确认依赖装进了 MaiBot 实际使用的 Python 环境，再重新加载插件。 |
